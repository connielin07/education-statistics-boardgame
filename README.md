# Education Statistics Board Game

This project is an interactive web-based board game built with public education statistics.  
It converts school-related statistical indicators into game rules, event cards, and scoring mechanisms.

本專案以教育公開資料為基礎，設計一款互動式統計桌遊網頁。玩家透過學校資料、事件卡與分數規則，理解招生、留校、資源分配與教育公平等議題。

## Project Purpose

The purpose of this project is to transform public education data into an interactive learning experience.  
Instead of only presenting statistics in tables, this project uses game rules to help users understand data comparison, probability, and decision-making.

## Features

- Interactive web-based board game
- Public education data application
- School profile and indicator-based scoring
- Event card mechanism
- Resource allocation simulation
- Statistical comparison and decision-making rules
- JavaScript-based game interaction
- GitHub Pages deployment support

## Tech Stack

- HTML
- CSS
- JavaScript
- Public education statistics
- GitHub Pages

## Game Concept

Players act as education resource planners.  
They make decisions based on school-related indicators such as enrollment, dropout rate, school type, region, or gender ratio.  
Different events may affect the final score, creating a simple simulation of statistical decision-making.
